Zigbee Live Map for SmartThings · RSSI / LQI · Mesh

Paste a SmartThings Personal Access Token. Create one at account.smartthings.com/tokens with Devices → List all devices + See all devices (add Control all devices to use "remove ghost"). New tokens expire after 24h.

The token is used only in your browser and is sent only to api.smartthings.com. Devices show LQI/RSSI only if their Edge driver reports signal metrics; the Mesh tab needs drivers that report Zigbee neighbor tables.
